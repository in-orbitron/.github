# Orbitron

Orbitron is a modular Discord bot written in Python. The **in-orbitron** organization is preparing the project and maintains its official version. There is no official hosted instance yet.

## Project

- [orbitron-core](https://github.com/in-orbitron/orbitron-core) - contains the bot's core. Extensions are intended to be developed in separate repositories.

## Get involved

Suggestions, feature proposals, and contributions from new collaborators are welcome. The organization reviews proposals and ideas from the community.

Have a question, found a bug, or want to suggest an improvement? Open an issue in the [orbitron-core issue tracker](https://github.com/in-orbitron/orbitron-core/issues).
